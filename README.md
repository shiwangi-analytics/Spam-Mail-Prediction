# Spam Mail Prediction using Machine Learning

## Project Overview

This project focuses on building a Machine Learning model to classify messages as **Spam or Not Spam (Ham)** using Natural Language Processing (NLP) techniques.

The model uses TF-IDF Vectorization to convert text messages into numerical features and Logistic Regression for classification.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- NLP

## Machine Learning Techniques

- Text Preprocessing
- TF-IDF Vectorization
- Logistic Regression
- Model Training and Testing
- Model Evaluation

## Project Workflow

1. Importing libraries and dataset
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Converting text into numerical features using TF-IDF
5. Splitting data into training and testing sets
6. Training the Logistic Regression model
7. Predicting Spam and Ham messages
8. Evaluating model performance

## How to Run

1. Clone this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Open the Jupyter Notebook.
4. Run all cells to train and test the model.

## Project Objective

To develop a text classification model that can identify spam messages and distinguish them from legitimate messages.
